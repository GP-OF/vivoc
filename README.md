# vivoc

Geplante iPhone-App zum Vokabeltraining.

Die [Schritt-für-Schritt-Checkliste](CHECKLISTE.md) führt von der Planung über die Entwicklung mit Swift und SwiftUI bis zur Veröffentlichung. Jeder Arbeitsschritt enthält eine Erklärung und ein überprüfbares Ergebnis.

Aktueller Stand: Planung; eine ausführbare App ist noch nicht vorhanden.
